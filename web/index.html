◗定时任务
自动化定时器
❓定时任务怎么用
  1. 直接对小爱说：每天七点半打开热水器、工作日早上八点打开客厅灯、每周一三五晚上十点关闭客厅空调、三分钟后关闭餐厅空调。
  2. 自然语言解析依赖 AI 托管（高级设置里开启并填好 API Key）。没开 AI 时只能用手写意图规则，或直接到 HA 里建自动化。
  3. 带每天 / 工作日 / 周末 / 星期几 + 时间的指令，会在 HA 里创建一条自动化，实体名形如 automation.xiaoai_bridge_1750000000；本页可查看启用状态和上次触发时间。
  4. 「N 分钟后…」属于延迟执行，跑在桥接器内存里，本页看不到；重启桥接器会丢，重要的事请用「每天几点」。
  5. 本页只列出桥接器创建的自动化；点 ✕ 删除会同时从 HA 配置里移除并重载，不会动你手写的其它自动化。
  6. 口语时间都认得：七点半、19:00、晚上十点、下午三点一刻、每天中午十二点。

🔒面板访问保护
给配置面板加一层 HTTP Basic 认证，防止同网络的人打开面板改配置或偷 Token。默认关闭；开启后访问面板需要输入下面的账号密码。
⚠ 启用后浏览器会弹登录框。忘记密码可编辑服务器上的 config/config.yaml，把 web_auth.enabled 改成 false。Basic 认证是明文口令，公网访问请务必套 HTTPS 或反向代理。
